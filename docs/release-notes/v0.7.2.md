### Yeni
- Yazı tipi paketleri artık başlıkları ve kodu da değiştiriyor. IBM Plex paketinde başlıklar Fraunces, metin Plex Sans, kod Plex Mono.
- Beş yeni paket: Bricolage, Editorial, Space, Literata ve Nunito. Ayarlar'da her paketi kendi yazı tipiyle görerek seçebilirsin.
- Tablo hücresine sağ tıklayınca satır/sütun ekleme, silme, başlık satırı ve hizalama menüsü açılıyor.
- Ayarlar → Güncellemeler'de "Şimdi denetle" düğmesi: yeni sürüm var mı, istediğin an bakabilirsin.

### Düzeltmeler
- Açık temada kod blokları artık sayfadan belli oluyor (biraz koyu zemin ve ince kenar).
- Yeni sürüm, dosyaları tam yüklenmeden önerilmiyor; "Güncelle" her zaman çalışır hâlde geliyor.

### New
- Font packs now change headings and code too. The IBM Plex pack uses Fraunces for headings, Plex Sans for text and Plex Mono for code.
- New packs: Bricolage, Editorial, Space, Literata and Nunito. Settings shows each pack in its own fonts.
- Right-click a table cell to add or delete rows and columns, toggle the header row and set alignment.
- Settings → Updates has a "Check now" button.

### Fixes
- Code blocks stand out in the light theme (slightly darker background and a thin border).
- A new version is not offered until its files are uploaded, so "Update" always works.
